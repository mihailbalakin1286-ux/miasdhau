# RemoteControl Web — просмотр экрана через интернет

Это приложение передаёт экран через WebRTC **только после явного разрешения** владельца. Управления компьютером нет.

## Развёртывание на Vercel
1. Создайте базу Upstash Redis (REST API).
2. В Vercel создайте проект из этой папки (Framework Preset: Other).
3. В Environment Variables добавьте `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN` из Upstash.
4. Разверните проект. Оба пользователя открывают один HTTPS-адрес сайта.
5. Зритель вводит девятизначный ID владельца. Владелец подтверждает запрос и выбирает экран в браузере.

## Ограничения
- Прямой WebRTC с публичным STUN может не пройти через некоторые NAT/корпоративные сети. Для надёжной работы добавьте собственный TURN-сервер и параметры `iceServers` в index.html.
- Демо не рассчитано на публичный массовый сервис: нужны аутентификация, защита от спама и лимиты запросов, а также более надёжная обработка сигнализации.
- ID случайный и кратковременный. Не сообщайте его посторонним.
- HTTPS обязателен для getDisplayMedia. Работает в современных настольных браузерах.
- Redis содержит кратковременные сообщения сигнализации (не видеопоток).
